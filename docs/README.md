# MCP Gateway user guide

This guide is for people who run MCP Gateway on a Mac and connect MCP clients to it.
It covers installing the app, adding servers, connecting clients and fixing common failures.
It does not cover building or releasing the app; `DEVELOPMENT.md` and `RELEASING.md` cover those tasks.

## Reading order

- [Getting started](getting-started.md): install the app and serve your first server.
- [Using the app](using-the-app.md): the window, drafts, the menu-bar icon, logs and updates.
- [Servers](servers.md): local commands, HTTP servers, keys and the Bear preset.
- [Connect a client](clients.md): setup for six clients, and protocol compatibility.
- [Remote access](remote-access.md): LAN, Tailscale and WireGuard addresses.
- [Security](security.md): what the gateway enforces and how to share safely.
- [Configuration](configuration.md): the configuration file and environment variables.
- [Troubleshooting](troubleshooting.md): status codes and common failures.
